# 12. Glossary

| Term | Meaning |
|------|---------|
| Prüfstand | test bench / dynamometer station |
| Trägheitsprüfstand | inertia dynamometer (accelerates a known mass) |
| Rollenprüfstand | roller dynamometer (vehicle drives rollers) |
| Simulation | software stand-in for the real bench hardware |
| ADR | architecture decision record |
