# 2. Constraints

| Type | Constraint |
|------|------------|
| Hardware | Arduino/ESP32 controls the physical hardware; Raspberry Pi collects data and hosts the GUI |
| Technology (planned) | Python (Litestar, Polars, DuckDB), TypeScript (Svelte, Vite), C++ for Arduino/ESP32, Docker deployment |
| Organisational | hobby project, monorepo, GitHub Actions CI/CD, Copilot agents |
| Documentation | technical docs per subproject, end-user docs served on the Pi |

The technology list is a stated intention from the kickoff, not a verified architecture decision.
