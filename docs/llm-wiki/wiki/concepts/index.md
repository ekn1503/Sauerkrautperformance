# Concepts

* [Documentation structure](documentation-structure.md) - the three documentation sets in the global docs/ folder: internal technical docs, end-user docs served on the Raspberry Pi, and this LLM wiki.
* [Monorepo conventions](monorepo-conventions.md) - tooling and lint conventions for the Sauerkrautperformance monorepo (no application architecture decided yet).
* [Simulation mode](simulation-mode.md) - requirement that every test bench can be developed and tested without hardware by a simulation that behaves like the real device.
