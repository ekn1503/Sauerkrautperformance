# Entities

* [Dynamometer test bench (moped)](dynamometer-test-bench.md) - generic measurement station for mopeds: ESP32/Arduino controls the hardware, a Raspberry Pi collects data and shows a Svelte GUI, a Python backend stores and evaluates measurements; bench type still open.
* [Sauerkrautperformance monorepo](sauerkrautperformance.md) - the hobby monorepo that hosts several subprojects, starting with a generic moped dynamometer test bench.
