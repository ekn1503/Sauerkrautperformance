# Sauerkrautperformance User Guide

Welcome. This guide explains how to operate the Sauerkrautperformance measurement stations. It is served directly from the station (Raspberry Pi), so it is available without internet access.

Start with [Safety](safety.md). Per-bench guides live in subfolders (for example `dyno/`) and are added as the stations get built.

!!! note "Work in progress"
    The first bench (a moped dynamometer; type not fixed yet) is still in planning. This guide is a skeleton.
